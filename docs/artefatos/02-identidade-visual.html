Como funciona

1

Escolha o serviço

Veja os serviços disponíveis, os preços e o tempo de cada um. Combos têm desconto automático.

2

Veja os horários

O sistema mostra só o que está disponível, com base na agenda real dos barbeiros.

3

Escolha o barbeiro

Ou comece pelo barbeiro se preferir alguém específico. Você vê o portfólio antes de decidir.

4

Confirme presença

Você recebe um email com o link de confirmação. Confirme até 2h antes e apareça no horário.
