# Documentação — barbearia-php

Esta pasta contém toda a documentação de planejamento e governança do projeto.

## Arquivos

| Arquivo | O que é |
|---------|---------|
| `DISCUSSAO.md` | Transcrição completa do planejamento inicial (não editar) |
| `RELATORIO.md` | Relatório de desenvolvimento — atualizar a cada sessão |
| `ROADMAP.md` | Etapas e tasks do projeto — marcar tasks conforme avança |
| `TESTES.md` | Regras e padrões de testes automatizados |
| `artefatos/01-brief.html` | Brief do projeto (abrir no navegador) |
| `artefatos/02-identidade-visual.html` | Identidade visual e tokens de design (abrir no navegador) |
| `artefatos/03-documento-tecnico.html` | Documento técnico completo de implementação (abrir no navegador) |

## Ordem de leitura para o agente

1. `artefatos/01-brief.html` — entender o projeto e suas regras de negócio
2. `artefatos/02-identidade-visual.html` — entender a identidade visual e tokens CSS
3. `artefatos/03-documento-tecnico.html` — entender a arquitetura técnica, schema, contratos de páginas
4. `ROADMAP.md` — ver qual fase e tasks estão pendentes
5. `TESTES.md` — seguir as regras de testes antes de commitar
6. `RELATORIO.md` — atualizar ao final de cada sessão
